# Maaz Khurram Portfolio Website

A responsive, single-page portfolio website built with plain HTML, CSS, and JavaScript. No build step or framework is required.

## Preview locally
1. Download and unzip this project.
2. Open `index.html` in your browser.

## Deploy with GitHub + Vercel
1. Create a GitHub repository (for example, `maaz-portfolio`).
2. Upload `index.html` and `README.md` to the repository's root.
3. Go to https://vercel.com and sign in with GitHub.
4. Choose **Add New → Project**, import your repository, and deploy.
5. For a plain HTML site, leave the framework preset as **Other** and the build command empty. The root directory should be `./`.
6. After deployment, Vercel gives you a live URL. Each new commit to the connected branch can trigger a new deployment.

## How to edit
Open `index.html` in GitHub and click the pencil/edit icon. Change the text or links, then commit your changes. Vercel will redeploy automatically if the repository is connected.

### Important things to customize
Search in `index.html` for:
- `Maaz Khurram` — name and branding
- `hello@example.com` — replace with your real email (update both `mailto:` and visible email)
- `Company Name` — experience details
- `yourprofile` — LinkedIn / Behance links
- `Download Resume` — add your resume PDF and link the button to it
- `images.unsplash.com` — sample remote images; replace URLs with your own project and portrait image URLs

This is a starter implementation based on the supplied screenshot. The text, sample projects, photos and testimonials are placeholders and should be personalized before sharing publicly.
